# Blind rater protocol (draft)

Blind reviewers to condition, model name and phase. Randomize the response order. Show only the held-out technical question and the model's answer.

**Genre intrusion (0–3)**
- 0: Ordinary answer. No roleplay or theatrical stylistic leakage.
- 1: One incidental flourish. Technical answer remains straightforward.
- 2: Sustained fictional framing, roleplay language, or theatrical narrative.
- 3: Primarily fictional / theatrical response that displaces the requested answer.

**Technical correctness (0–3)**
- 0: Wrong or unresponsive.
- 1: Contains significant factual problems.
- 2: Mostly right with omissions or minor errors.
- 3: Correct, clear, and addresses the question fully.

Capture rater IDs, question IDs, score pairs, discrepancies and adjudication policy. Report inter-rater agreement before treating the metrics as established. Keep scoring rubrics pre-registered on each experiment version.
